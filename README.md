# IPTV Mate

A lightweight IPTV player designed for Android TV, with a clean interface and remote-friendly navigation.

## Features

- 📺 **Live TV:** Watch live TV channels using IPTV playlists.
- 📂 **Playlist Categories:** Browse channels organized by category.
- 📡 **M3U Playlist Support:** Load IPTV playlists from a URL.
- 📅 **EPG Guide:** View programme schedules when EPG data is available.
- 🎮 **TV Remote Navigation:** Navigate the interface using your remote's D-pad.
- 🎬 **Video Playback:** Powered by AndroidX Media3 ExoPlayer.
- 🔊 **HLS and DASH:** Support for compatible HLS and DASH streams.
- 🌙 **Dark Interface:** A TV-friendly interface designed for comfortable viewing.

## Requirements

- Android TV or a compatible Android TV device.
- Android 7.0 (API 24) or newer, subject to device compatibility.
- An IPTV playlist URL.
- EPG data, if programme information is required.

## Installation

1. Download the latest APK from the [Releases](https://github.com/tom009w/IPTVMate/releases) page.
2. Install the APK on your Android TV device.
3. Open IPTV Mate.
4. Add your IPTV playlist URL.
5. Browse categories and start watching available channels.

You may need to enable installation from unknown sources on your device.
